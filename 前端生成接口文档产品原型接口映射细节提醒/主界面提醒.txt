【CENTER-1-E】最近交易记录 — 接入真实交易历史
当前： 5条静态假数据
建议： 页面初始化时调用 [23] GET /simulation/trade/history?page=1&size=5
代码里其实已经写了：
JavaScript
// 4.3 加载最近交易记录
const history = await fetchTradeHistory(1, 5);
if (history && history.list) {
    renderTradeRecords(history.list);
}
问题： 你的 fetchTradeHistory 函数返回的是 PageResult，但 renderTradeRecords 接收的是 records 数组。需要确认 history.list 还是 history.records 还是 history.data？
根据你的 PageResult 定义：
java
@Data
@Builder
public class PageResult<T> {
    private List<T> list;  // ← 应该是 list
    private Long total;
    private Integer page;
    private Integer size;
    private Integer pages;
}
所以 history.list 是对的。但你的代码里：
JavaScript
const history = await fetchTradeHistory(1, 5);
if (history && history.list) {  // ← 这里
    renderTradeRecords(history.list);
}
fetchTradeHistory 返回的是 apiRequest 的结果，也就是 data 字段的内容。如果后端返回：
JSON
{
  "code": "A00000",
  "data": {
    "list": [...],
    "total": 100,
    "page": 1,
    "size": 5,
    "pages": 20
  }
}
那 history 就是 data 对象，history.list 是对的。

【RIGHT-1-B】排行榜 — 确认是否已调用
代码里已写：
JavaScript
// 4.4 加载排行榜
await fetchLeaderboard();
但 renderLeaderboard 可能有问题： 你的 Mock 数据里有 rank 字段，但 API 返回的 LeaderboardVO 也有 rank。需要确认字段名是否一致。
LeaderboardVO 字段：
java
private int rank;
private Long userId;
private String nickname;
private BigDecimal totalProfit;
你的 renderLeaderboard：
JavaScript
return `
    <div class="rank-item">
        <div class="rank-num ${rankClass}">${item.rank || (index + 1)}</div>
        ...
        <div class="rank-profit">+¥${formatMoney(item.totalProfit)}</div>
    </div>
`;
这里 item.rank 应该是 item.rank，但你的 API 返回的是 LeaderboardVO，字段名是 rank（小写）。Java 的 rank 序列化到 JSON 也是 rank，所以没问题。
