一、系统概述与架构说明
================================================================================

本项目采用 Spring Cloud 微服务架构，所有请求通过 Gateway 统一入口。

  ┌─────────────────────────────────────────────────────┐
  │                    Nacos 注册中心                     │
  │                  192.168.153.129:8848                 │
  └─────────────────────────────────────────────────────┘

  客户端(浏览器/App)
       │
       ▼
  ┌──────────┐                                      ┌──────────┐
  │ Gateway  │────── 路由分发 ──────►  各微服务实例       │ Redis   │
  │  :8080   │                                              │ :6379   │
  └──────────┘                                      └──────────┘
       │                                                    │
       ▼                                                    ▼
  ┌──────────┐                                      ┌──────────┐
  │ Sa-Token │  认证鉴权                                 │ RabbitMQ  │
  └──────────┘                                      └──────────┘

微服务模块与服务端口：
  服务名称                 端口      职责说明
  ─────────────────────────────────────────────────────────
  gold-gateway             8080    统一网关入口
  gold-user-service        8081    用户注册/登录/认证
  gold-admin-service       8081    管理端(Feign代理到product)
  gold-simulation-service  8082    模拟交易(买卖/持仓/账户)
  gold-order-service       8084    实物商城订单/支付
  gold-mall-service        8085    商城前台(Feign代理到product)
  gold-market-service      8086    行情价格/K线
  gold-store-service       8087    门店管理
  gold-product-service     8088    商品/活动/库存核心服务
  gold-file-service        8088    文件上传OSS
  gold-news-service        8089    资讯/新闻/AI简报

技术栈亮点：
  - Spring Boot 3.x + Spring Cloud + MyBatis-Plus
  - Sa-Token (用户认证，token有效期24h，活跃超时30min)
  - Seata TCC (分布式事务，库存扣减)
  - RabbitMQ (延迟消息，订单超时取消)
  - Redis (排行榜缓存、行情缓存、Geo位置查询)
  - Elasticsearch (新闻全文检索)
  - Sentinel (限流熔断)
  - Nacos (注册/配置中心)

二、网关与认证
================================================================================

2.1 请求路由规则

  所有客户端请求统一访问 Gateway (端口 8080)，格式如下：

    http://{host}:8080/api/{service-name}/{controller-path}

  Gateway 自动将 /api/{service-name} 剥离后转发到对应服务：

    客户端请求                              →  转发到微服务
    ─────────────────────────────────────────────────────────────
    /api/user/**                           →  gold-user-service:8081
    /api/admin/**                          →  gold-admin-service:8081
    /api/simulation/**                     →  gold-simulation-service:8082
    /api/order/**                          →  gold-order-service:8084
    /api/mall/**                           →  gold-mall-service:8085
    /api/market/**                         →  gold-market-service:8086
    /api/store/**                          →  gold-store-service:8087
    /api/product/**                        →  gold-product-service:8088
    /api/file/**                           →  gold-file-service:8088
    /api/news/**                           →  gold-news-service:8089

  示例：客户端请求 POST http://localhost:8080/api/user/login
        → 网关剥离 /api/user，转发到 http://gold-user-service:8081/login

2.2 认证方式 (Sa-Token)

  认证方式：Bearer Token
  登录后在请求头中携带：  Authorization: Bearer {token}

  Token 配置：
    - 有效期：24小时
    - 活跃超时：30分钟（30分钟内无操作自动过期）
    - 支持同端互斥登录

  获取Token方式：
    用户登录：  POST /api/user/login   → 返回 UserLoginVO.token
    商户登录：  POST /api/merchant/login → 返回 MerchantLoginVO.token

  登出：
    POST /api/user/logout（需携带Token）

  用户身份传递机制：
    网关从请求头 "X-User-Id" 读取用户ID，通过内部 Feign 请求头传递到下游服务。
    下游服务通过拦截器将 userId 存入 UserContext ThreadLocal 中。
    Controller 层统一通过 UserContext.getUserId() 获取当前用户ID，不信任客户端传参。

三、统一响应格式
================================================================================

3.1 通用响应体 Result<T>

  所有接口返回值统一包裹在 Result<T> 中：

  {
    "code": "A00000",          // String 错误码，A00000=成功，其他=失败
    "msg": "success",          // 错误提示信息
    "data": { ... },           // 业务数据(泛型T)，成功时返回
    "requestId": "a1b2c3d4",   // 链路追踪ID(8位UUID)，异常时生成
    "extraData": { ... }       // 异常附加数据(Map/Object)，参数校验异常时返回字段错误详情
  }

  成功示例：
  {
    "code": "A00000",
    "msg": null,
    "data": { "id": 1, "username": "zhangsan", "token": "xxx..." },
    "requestId": null,
    "extraData": null
  }

  失败示例(参数校验)：
  {
    "code": "A00001",
    "msg": "参数验证失败: 用户名不能为空",
    "data": null,
    "requestId": "f3e8a1b2",
    "extraData": { "username": "用户名不能为空" }
  }

  失败示例(业务异常)：
  {
    "code": "A02003",
    "msg": "库存不足",
    "data": null,
    "requestId": "d4c5b6a7",
    "extraData": null
  }

3.2 分页响应体 PageResult<T>

  分页接口统一使用 PageResult<T>：

  {
    "list": [ ... ],     // 当前页数据列表
    "total": 100,        // 总记录数(Long)
    "page": 1,           // 当前页码(Integer)
    "size": 10,          // 每页大小(Integer)
    "pages": 10          // 总页数(Integer)
  }

  注意：部分接口使用 MyBatis-Plus 的 Page<T> (包含 records/total/size/current/pages 字段)，
       功能和 PageResult 一致，字段名略有差异。

3.3 全局异常处理 (GlobalExceptionHandler)

  系统使用 @RestControllerAdvice 统一处理所有异常，覆盖9种异常类型：

  异常类型                            HTTP状态码  错误码        说明
  ──────────────────────────────────────────────────────────────────────
  BusinessException                   400        业务自定义     自定义业务异常
  SystemException                     500        B00001        自定义系统异常
  MethodArgumentNotValidException     400        A00001        @RequestBody JSON参数校验
  BindException                       400        A00001        表单参数校验
  ConstraintViolationException        400        A00001        单个参数校验
  HttpMessageNotReadableException     400        A00001        JSON格式错误
  FeignException                      503        A00005        远程服务调用失败
  DuplicateKeyException               400        A00007        数据库唯一索引冲突(重复提交)
  Exception (兜底)                    500        B00001        未知系统异常

  所有异常响应均携带 requestId (8位UUID)，便于日志追踪。

四、统一错误码
================================================================================

  错误码遵循 A-BB-CCC 模型：

  成功:
    A00000  操作成功

  通用域 (00):
    A00001  参数校验失败
    A00002  资源不存在
    A00003  资源已存在/重复
    A00004  资源状态不允许操作
    A00005  并发冲突/系统繁忙
    A00006  线程中断
    A00007  请求已处理(幂等)
    A00008  远程调用异常
    A00009  消息创建失败

  用户中心 (01):
    A01001  用户名已存在
    A01002  密码错误
    A01003  手机号错误
    A01004  账户不存在

  商品中心 (02):
    A02001  商品/规格不存在
    A02002  规格已停售
    A02003  库存不足
    A02004  规格已关联活动
    A02005  库存不能为负数

  活动中心 (03):
    A03001  活动不存在
    A03002  活动状态不允许操作
    A03003  活动商品已存在
    A03004  活动商品已关联其他活动
    A03005  活动库存不能低于已售出
    A03006  活动库存已售罄
    A03007  活动未开始或已结束
    A03008  活动正在进行

  交易中心 (04):
    A04001  余额不足
    A04002  持仓不足
    A04003  行情获取失败
    A04004  行情价格异常
    A04005  重量/金价/工费不能为空
    A04006  Token过期
    A04007  支付创建失败

  门店 (05):
    A05001  门店不存在
    A05002  经纬度不能为空

  系统错误 (B):
    B00001  系统内部错误
    B00002  数据库操作失败
    B00003  分布式锁异常

  第三方错误 (C):
    C06001  OSS上传失败
    C06002  支付宝调用失败
    C06003  支付宝客户端异常

5.1 用户注册
  ───────────────────────────────────────────────────────────────
  POST  /api/user/register
  认证：无需Token

  请求体 (JSON):
  ┌──────────┬─────────┬───────────────────────────────────┐

  │ fee          │ BigDecimal  │ 手续费(费率0.1%)                │

  └─────────────┴─────────────┴─────────────────────────────────┘
